│ FEATURES IMPLEMENTED                                                         │
└─────────────────────────────────────────────────────────────────────────────┘

✅ Native macOS UI with Tauri
   • Clean, modern interface following macOS design guidelines
   • System-native controls (sliders, dropdowns, switches)
   • Dark/light mode support (auto-detects system preference)
   • Responsive layout (800x600 minimum, 1000x700 default)

✅ Text-to-Speech Interface
   • Multi-line text input area
   • Paralinguistic tag buttons ([laugh], [chuckle], [sigh], etc.)
   • Model selection (Turbo, Multilingual, Standard)
   • Language selection (23+ languages for Multilingual model)
   • Voice cloning via reference audio upload

✅ Advanced Parameter Controls
   • Temperature: 0.05 - 2.0 (slider)
   • Top P: 0.0 - 1.0 (slider)
   • Top K: 0 - 1000 (slider)
   • Repetition Penalty: 1.0 - 2.0 (slider)
   • Min P: 0.0 - 1.0 (slider)
   • Normalize Loudness: checkbox
   • Random Seed: number input

✅ Output Configuration
   • Format selection: MP3, WAV, OGG
   • Smart filename generation (date-snippet-model-params.format)
   • Custom filename support
   • Save to any location

✅ Settings Panel
   • Models download path configuration
   • Theme selection (Auto/Light/Dark)
   • UI language selection
   • Virtual environment path display
   • One-click dependency installation

✅ Python Environment Isolation
   • Uses Python venv (not Docker)
   • No system Python pollution
   • Self-contained dependencies
   • Easy setup and maintenance

┌─────────────────────────────────────────────────────────────────────────────┐
│ GETTING STARTED                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

1. Setup (First Time):
   $ ./scripts/setup.sh
   $ npm install

2. Development:
   $ ./scripts/run-dev.sh          # Terminal 1: Start backend
   $ npm run tauri:dev             # Terminal 2: Start Tauri app

3. Build for Distribution:
   $ ./scripts/build-macos.sh      # Creates DMG in src-tauri/target/release/bundle/dmg/
